# Implement the calculator module

The file `calc.py` in the workspace root contains two unimplemented
functions. Implement them:

- `add(a, b)` returns the sum of `a` and `b`.
- `sub(a, b)` returns `a` minus `b`.

Both must work for negative numbers. Do not change the function signatures.
The tests in `tests/` will be run to verify your work.
