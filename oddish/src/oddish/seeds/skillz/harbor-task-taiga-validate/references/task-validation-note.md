# Task Validation Note

## Purpose

Record the validation status of one converted task for review and tracking.

## Capture

- task name
- validation date
- environment name or ID
- problem version or task version
- Taiga job ID, if available
- QA job ID, if available
- outcome
- current classification
- next action or blocker

## Guidance

- Use one note per meaningful validation step.
- Keep validation notes separate from task-file commits when possible.
- Treat this note as tracking, not as policy.
